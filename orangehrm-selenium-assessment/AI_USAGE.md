# AI Tool Usage

AI usage is a mandatory part of this assessment.

## Tools used

### ChatGPT
Used for:
- reviewing the assessment requirements;
- framework structure and Page Object Model design;
- troubleshooting Selenium/API assertions;
- reviewing OrangeHRM API validation logic;
- performance-test planning;
- README and submission documentation.

### GitHub Copilot / Selenium MCP
Where available, used for:
- code completion and refactoring;
- live browser/DOM inspection;
- locator validation;
- test-code assistance.

## Validation responsibility

AI output was not treated as automatically correct. Generated suggestions were reviewed against the application, compiled, executed, and adjusted where required.

## Example prompt log

1. "Review this OrangeHRM employee lifecycle test and identify brittle Selenium locators."
2. "Inspect the OrangeHRM Job Details page and verify stable locators for Job Title and Employment Status."
3. "Review the API response and identify the correct nested fields for Job Title and Employment Status."
4. "Create a light JMeter smoke test that does not overload the public demo environment."
